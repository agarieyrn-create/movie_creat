# /new-video — 新しい動画台本を作成してパイプライン実行

テーマや話題を入力すると、台本を生成して `script.json` に保存し、そのままパイプラインを実行する。
`$ARGUMENTS` にテーマを渡す（例: `/new-video AIが仕事を変える未来`）。

## 手順

1. `$ARGUMENTS` のテーマをもとに、以下の形式で台本を生成する:

```json
[
  {
    "speaker": "momo",
    "text": "（導入・問いかけ文）",
    "displayText": "（画面表示テキスト）",
    "pauseAfter": 0.5
  },
  {
    "speaker": "popo",
    "text": "（リアクション・展開）",
    "displayText": "（画面表示テキスト）",
    "pauseAfter": 0.3
  }
]
```

**台本生成ルール:**
- 話者は `momo`（進行役）と `popo`（リアクション役）を交互に使う
- 1行あたり30〜60文字以内（短めにして聞き取りやすくする）
- 全体で5〜8行（ショート動画1本分：30〜60秒想定）
- `text` は TTS 読み上げ用（自然な話し言葉）
- `displayText` は画面表示用（句読点や改行を整える）
- `pauseAfter` は文末の間（秒）: 文末0.5、短い返しは0.3

2. 生成した台本を `script.json` に書き込む（既存の内容は上書きする）
3. 内容をユーザーに確認してもらう
4. OKであれば `npm run pipeline` を実行する
